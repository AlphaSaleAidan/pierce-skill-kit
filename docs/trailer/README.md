# Trailer (work in progress)

A 38-second trailer for the kit, made entirely with code by Claude: HTML/CSS frames captured with Playwright and
encoded with ffmpeg. The hub footage is a real run of the kit in a throwaway container (with a stand-in for Claude),
and every line on screen is real text from that run or from [RULES.md](../../RULES.md).

- [trailer.mp4](trailer.mp4): 1920x1080, 30 fps, silent, 3.7 MB
- [teaser.gif](teaser.gif): the "reports land" beat, 960 px wide

**Honest status:** an independent grader, comparing against Linear, Warp and Raycast trailers, scored it 5/10. Its
biggest open note: the middle beats are small cards in a big empty frame. Fill the frame, animate each report
travelling from its tab to the lead, end on the hero. That's why it lives here and not on the front page yet.
