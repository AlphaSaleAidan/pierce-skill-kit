# Where to get components and assets

Grouped by what you need. **Licence** is the usual one; always confirm on the item itself.
"Blocks bots" = the site often refuses automated fetches; search it in a browser or with `site:` web search.

## UI components (React + Tailwind unless noted)
| Source | Good for | Licence | Search |
|---|---|---|---|
| [shadcn/ui](https://ui.shadcn.com/docs/components) | the base kit: buttons, forms, dialogs, tables | MIT | component list on the page |
| [21st.dev](https://21st.dev/community/components) | huge community catalogue of shadcn-style components | varies per component; full source needs a paid key | site search |
| [Magic UI](https://magicui.design/docs/components) | marketing-page pieces: marquees, bento grids, number tickers | MIT | sidebar list |
| [Aceternity UI](https://ui.aceternity.com/components) | showy hero effects, cards, backgrounds | free + paid "pro" | component list |
| [React Bits](https://reactbits.dev) | animated text, backgrounds, cursors | MIT + Commons Clause | sidebar list |
| [KokonutUI](https://kokonutui.com) | polished cards, AI-chat inputs, buttons | MIT | component list |
| [coss ui (was Origin UI)](https://coss.com/ui) | lots of small form inputs and controls | MIT | site search |
| [Motion Primitives](https://motion-primitives.com) | animated building blocks on Motion | MIT | component list |
| [Cult UI](https://www.cult-ui.com) | unusual shadcn-style components | MIT | component list |
| [HyperUI](https://www.hyperui.dev) | plain Tailwind HTML sections, no React needed | MIT | category pages |
| [Flowbite](https://flowbite.com/docs/getting-started/introduction/) | Tailwind components with plain JS | MIT (pro is paid) | docs sidebar |
| [daisyUI](https://daisyui.com/components/) | Tailwind class-name components | MIT | component list |
| [Radix Primitives](https://www.radix-ui.com/primitives) | unstyled, accessible behaviour (menus, popovers) | MIT | docs |
| [Headless UI](https://headlessui.com) | unstyled accessible components (React/Vue) | MIT | docs |
| [Uiverse](https://uiverse.io) | single HTML/CSS elements: buttons, loaders, toggles | MIT | site search (blocks bots) |
